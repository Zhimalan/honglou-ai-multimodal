## 三、分析与结论

### 1. 检索能力

- 方案A无检索能力，Recall@5=0；方案B引入多级增强RAG后Recall@5=0.75；方案C Recall@5=0.68（BGE+BM25+RRF，未启用Reranker）。
- 方案B与C检索路径略有差异（B含HyDE+Reranker精排，C因Windows环境CrossEncoder段错误未启用），核心检索能力（向量召回+BM25+RRF融合）一致，但B的Reranker精排使Recall@5高出7个百分点。

### 2. 生成质量

- **事实准确**：A=2.64 → B=3.58 → C=2.62（C vs B: -0.96）。方案B最优，微调模型（C）未超越纯RAG方案。
- **完整度**：A=2.56 → B=3.34 → C=2.42（C vs B: -0.92）。方案C完整度最低，主因是微调模型在简单问答时倾向生成极短回答（如"第3回"），被judge评为低分。
- **无幻觉**：A=5.00 → B=4.92 → C=4.22。方案C幻觉控制最差，部分回答引用了错误回目的内容。

### 3. 幻觉抑制

- 方案A幻觉率=0.0%，方案B=2.0%，方案C=16.0%。
- 方案A虽无幻觉但事实准确率最低（2.64），属于"不知道但不编造"型；方案B通过RAG锚定原文，在保持较高事实准确（3.58）的同时将幻觉率控制在2%。
- 方案C幻觉率高达16%，分析原因：微调模型对领域知识产生了过度自信，在检索结果不理想时倾向基于训练记忆生成而非拒绝回答，导致引用错误回目或编造情节。典型案例如Q2（薛蟠打死冯渊）中，模型引用了"张三不肯换酒"等不存在的内容。

### 4. 核心结论

1. **RAG是最有效的单一增强手段**：方案B（Base+RAG）在所有指标上均优于方案A（纯Base）和方案C（微调+RAG），事实准确提升+0.94（A→B），完整度提升+0.78（A→B），验证了多级增强RAG（BGE向量+BM25+RRF+HyDE+Reranker）对红楼梦问答任务的有效性。
2. **QLoRA微调未带来预期增益**：方案C的事实准确（2.62）与方案A（2.64）持平，低于方案B（3.58）达0.96分。主要原因包括：（a）微调模型在简单回目定位题上生成极短回答（如"第16回"），被judge评为0分；（b）未启用Reranker导致检索精度下降；（c）训练数据中短回答模式影响了模型输出风格。
3. **幻觉率悖论**：方案A幻觉率最低（0%）但事实准确也最低（2.64），属于"安全但不准确"；方案C幻觉率最高（16%）但事实准确与A持平（2.62），属于"不安全且不准确"。方案B在准确性与安全性间取得了最佳平衡。
4. **分类别表现**：在诗词赏析类（3题）上三方案表现一致（fac=3.67~4.00, noh=5.00）；在人物关系类（9题）上A与B持平（fac=3.89）但C下降（3.44）；在剧情问答类（38题）上B显著优于A和C（fac=3.50 vs 2.24/2.34），说明RAG对需要定位具体情节的问题增益最大。
5. **局限性**：方案C因Windows环境CrossEncoder兼容性问题未启用Reranker精排，检索精度低于方案B；训练数据规模较小（约1000条QA对），微调效果有限；judge模型（Qwen2.5-7B via Ollama）对极短回答的评分可能存在偏差。
